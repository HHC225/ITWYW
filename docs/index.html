Describe the software feature you want. ITWYW helps you find its name.

ITWYW is an AI agent skill for Claude Code and Codex. It translates everyday descriptions of app behavior into recognizable UI/UX patterns, frontend components, backend features, and infrastructure concepts—then confirms what you mean.

Explore the GitHub project Installation instructions

What does ITWYW do?

Frontend & UI/UX

Find familiar names for interactions and components such as drawers, accordions, toasts, and sticky headers.

Backend features

Describe application behavior and identify concepts such as idempotency, authorization, and background jobs.

Infrastructure

Clarify requirements involving failover, hosting, networking, backups, and monitoring.

From a description to a feature name

“When I press the menu button, something should slide in from the right.”

Likely feature: Drawer (side panel). ITWYW explains the behavior and asks whether that matches the intended result.

Install the ITWYW agent skill

Install the itwyw skill in a coding project using the skills CLI:

npx skills add HHC225/ITWYW --skill itwyw

Alternatively, copy skills/itwyw into .claude/skills/ for Claude Code or .agents/skills/ for Codex. The skill files must remain together. See the README for supported paths and CLI prerequisites.

Frequently asked questions

What does ITWYW stand for?

ITWYW stands for Is This What You Want? The skill checks that a suggested development concept actually matches the user's intention.

Can ITWYW tell me what a UI component or animation is called?

It can suggest names for described frontend components and interaction patterns. If several features fit, it compares up to three possibilities and asks for confirmation.

Does ITWYW build the app for me?

ITWYW identifies and explains a requested feature before implementation; it is not an application generator or an architecture approval system.
